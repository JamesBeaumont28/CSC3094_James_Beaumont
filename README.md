# CSC3094 Dissertation

## Project overview: TLS scanning, Data enrichment and analysis
This project is a data gathering, enrichment and analysis tool used to survey the KEM protocols used by domains in a given dataset. The data can then be enriched, stored and analysed for further insights. 

## Features
- scans the list of given domains to find the supported groups with a iterative probing method. It has built in control systems such as a rate-limiter and error rate tracker. 
- The data can then be imported into a mySQL database ran on a docker container and this data can the nbe enriched with additional data such as region adn sector 
- The data can then be analysed with a jupyter script. 

## Setup Instructions
- Docker
- Docker desktop
- WSL (virtualization may need to be enabled on your machine)

### Initializing docker container
the container will be initialized automatically upon running any program that interacts with it. The function that do this are located in [import_data.py](database/import_data.py).

## Codebase structure and details
The [data-in](data-in) folder contains all files and programs for data import, such as converting the tranco domain rankings into a csv and downloading all data enrichment datasets.

[Database](database) contains all files related to the database, such as wiping, importing and enrichment. 

[Ingested-data](ingested-data) contains all the processed datasets such as the ranking csv and the datasets for enrichment.

[Jupyter](Jupyter) contains the jupyter file and any graphs that are generated by the jupyter file.

[Results](results) contains all the outputs from [scanner.py](zgrab2/scanner.py).
